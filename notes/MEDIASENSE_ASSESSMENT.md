## THE TASK

Write a command-line program that accepts a single argument — a path to a text file containing a large list of words, one per line. The program should re-organise the words so that all anagrams of each other appear together on a single line, separated by spaces.

**Usage example:** `my_program data_file.txt`

---

## EXAMPLE

### INPUT
```
apple
car
cider
tar
itch
rat
cried
helicopter
arc
```

### OUTPUT
```
apple
car arc
cider cried
tar rat
itch
helicopter
```
